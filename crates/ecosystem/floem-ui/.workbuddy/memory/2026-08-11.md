## API design — Providers
- Each provider: builder `new()` + `child(impl IntoView)` + a prop setter (`dark(bool)` etc.)
  + a typed signal getter (`dark_signal() -> RwSignal<bool>`, …). The getter returns the internal
  signal (no arg) — same contract as `open_signal()`.
- Documented limitation: Rust/Floem static dispatch means subtree-scoped re-theming is NOT
  enforced; descendants read the getter and react. (No scoped-context mechanism.)
