7. `floem-elements/src/<name>.rs` — `pub use` props + tokens + `#[cfg(feature)] pub use

### Reusable gotchas (Batch 8) — feed to future batches
- **`RwSignal<AnyView>` is NOT `IntoView`** (AnyView is NOT `Clone`). So a calendar cannot be a
  `RwSignal<AnyView>` updated via `create_effect`. Build a FIXED grid of 42 `label` cells
  (6×7); each cell reads `view_month: RwSignal<(i32,u32)>` reactively via pure helpers
  `is_leap`/`days_in_month`/`weekday_of_first`/`day_at`. Prev/next change the month; day clicks
  set value + close + fire `on_change`; blank leading/trailing cells `apply_if(!vis, hide())`.
- **Do NOT `h_stack_from_iter(c.to_vec())` on a `&[AnyView]`** — `to_vec()` requires `AnyView:
  Clone` (it isn't). Instead build each row by collecting owned `Vec<AnyView>` cells directly
  (`(0..7).map(|c| cell(r*7+c)).collect()`) and feed the owned `Vec` to `h_stack_from_iter`.
- **`opt` move triple-consumer bug** (Combobox/Autocomplete): `text(opt)` MOVES `opt`, then the
  `.style(move |s| … opt …)` matcher and `.on_event(move … opt …)` click handler also need it.
  Clone up front: `let opt_style = opt.clone();` (style) + `let opt_event = opt.clone();`
  (on_event) + `text(opt)` (consumes the original). Row clicks use `opt_event.clone()`.
- **Autocomplete `FocusLost` handler must be an INLINE block closure**, not a named `let`
  binding: `.on_event(listener::FocusLost, { let query=query; … move |_, _| { … } })`. Storing it
  in a `let commit_free_text = …` triggers "implementation of `FnMut` is not general enough"
  (the inferred closure type isn't HRTB-general). Inline gives the compiler the exact expected
  `on_event` signature → HRTB inference succeeds.
- **Autocomplete `options` move**: the `FocusLost` `move` closure captures `options` by move, so
  the later `rows` builder (which borrows `options.iter()`) fails with E0382. Clone `options`
  INSIDE the handler block (`let options = options.clone();`) so the outer `options` stays
  available for the rows.
- **`E0373` borrow in TimePicker stepper rows**: a `.style(|s| … cell_height)` that captures a
  non-`Copy` `cell_height` must be `.style(move |s| …)` (the closure must be `'static`).
- **`v_stack` is deprecated** → `Stack::vertical()` (warning only; `date_picker`/`time_picker`
  still use `v_stack` — fine for now).
- **Swap script is the source of truth for Cupertino/Fluent**: a python script does the
  deterministic rewrite so Material stays the single source. Replacements:
  `Md{Name}`→`{Prefix}{Name}`, `MaterialTheme`→`{Prefix}Theme`,
  `theme_signal()`→`RwSignal::new({Prefix}Theme::new())`, drop
