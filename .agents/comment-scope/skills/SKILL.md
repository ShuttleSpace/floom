# Comment Scope（注释范围）

## 1. 核心原则

代码应当尽量自解释。注释只服务于一件事：**防止读者在某一行踩坑**。

- 不写「代码在做什么」「为什么这样写（常规原因）」。
- 不写模块头部 / 函数头部的散文式说明块——那是文档（`docs/api/`）的事，不是代码的事。
- 只保留**非显而易见**的约束、歧义、平台 / 上游坑，并**紧贴那一行**写，放在最小作用域内，不要拉到文件头或函数头。
- 解释性、背景性、历史性的内容，挪到 `docs/api/` 文档里引用，不在代码里堆。

## 2. 判定表

### 保留（紧贴代码行上方）

满足以下任一才保留，且必须放在被保护语句的正上方、最小作用域内，只写一句：

1. **踩坑点 / 陷阱**：不写就会出 bug 或 panic。
   ```rust
   // 必须在 layout 之前调用，否则会 panic（见 #1234）
   compute_layout();
   ```
2. **反直觉的约束 / 不变式**：类型系统表达不出来的隐式规则。
   ```rust
   // index 从 1 开始，是平台 ABI 要求，不是 off-by-one
   let handle = sys::get(1);
   ```
3. **上游 / 平台 workaround**：带 issue 或 commit 指针，方便日后删除。
   ```rust
   // workaround for wgpu#999，升级后删除
   ```
4. **安全约束**（`unsafe` 块的 SAFETY 注释）：必留，写清为什么安全。

### 删除（直接删，无需迁移）

- 复述代码 obvious 行为的：`// 递增 i`、`// push 到 vec`、`// 返回结果`。
- 函数 / 变量名已说清的用途说明。
- 模块顶部 / 函数顶部的「本模块负责…」「本函数用于…」散文块。
- 过期的 TODO / FIXME（或转成 issue 后删）。
- 纯装饰性分隔注释（`// =====` 之类，除非真正分隔巨大区块）。

### 迁移到 docs/api/（保留一句指针或直接不写）

这些内容不属于某一行，挪到 `docs/api/<主题>.md`：

- 设计理由、架构总览、使用契约、跨多行的「行为保证」。
- 代码里只在真有必要才留 `// 见 docs/api/xxx.md`，否则不留。
- 公共 API 的 rustdoc（`///`）：
  - 若只是复述签名或泛泛而谈 → 删或迁移；
  - 若记录**参数 / 返回值 / panic / 安全性**等契约且精简 → 可留，但别写成散文。

## 3. 应用流程（清理某个文件时）

1. 通读文件，逐条过每个注释。
2. 按 §2 判定表分类：保留 / 删除 / 迁移。
3. 保留类：移到被保护语句正上方，删掉多余废话，只留一句。
4. 删除类：直接删。
5. 迁移类：内容写入 `docs/api/<主题>.md`（文件不存在就建，主题用小写中划线，如 `docs/api/layout-invariants.md`），代码里不留或只留一句指针。
6. 跑 `cargo fmt` 与 `cargo check`，确认没误删 rustdoc 测试所需内容、没把行内 `//` 当代码删掉、没破坏 `///` 示例。

## 4. 边界与护栏

- 不要为了删注释而删掉**必要的公共 API 文档**（floem 是库，契约级 rustdoc 有价值）。本规则针对的是散文式、复述式、堆在头部的注释。
- 不要删除测试文件里解释「为什么这个 case 重要」的注释——那属于踩坑 / 契约，留着。
- 删完必须 `cargo check` 通过；禁止误删实际代码。
- 迁移到 `docs/api/` 时，一段话对应一个主题文件，避免一个巨型注释文件。

## 5. 何时触发

- 新建 / 修改 Rust 代码、补注释、或做全仓注释清理时，先读本规则。
- 任何「要不要加注释」「这段注释该不该留」的取舍，按 §2 判定表来。

## 6. 前后对照示例

删除散文式头部：

```rust
// 本模块负责把平台的事件转换成 floem 的内部事件，
// 包括鼠标、键盘、触摸等。我们在这里做坐标换算
// 和按键映射，然后派发到应用层。
pub fn translate(event: PlatformEvent) -> AppEvent { ... }
```

→ 模块总览迁到 `docs/api/event-translation.md`，代码里只留真正必要的行内注释（若有坐标换算的坑，紧贴那一行写）。

删除复述式注释：

```rust
// 把计数加一
count += 1;
// 推入结果列表
results.push(value);
```

→ 直接删。
